# AlphaNeurons

A place to dump my raw thoughts — letters to my younger self, lessons for my future self, and a place to unload my brain every so often. No schedule, no theme. Just writing in public.

## Writing

- Posts are plain Markdown files in `src/content/blog/`
- Push to `master` — GitHub Actions builds and deploys automatically
- Live at https://hghotra.github.io/alphaneurons/

Built with [Astro](https://astro.build), hosted on GitHub Pages.
